# KeyboardKid 素材指南

## 默认皮肤「西西」

目录 `src/assets/xixi/`（224×278，手臂烘焙在图内，无程序手臂/尾巴）：

| 文件 | 触发 |
|------|------|
| `idle.png` | 默认态（与 `typing.png` 同图） |
| `blink.png` | 定时眨眼（缓入缓出叠化） |
| `privacy.png` | 输密码闭眼 |
| `typing.png` | 正常打字速度 |
| `typing_fast.png` | 快速打字 / 摸头开心 |

## 规范

- 使用 **透明 PNG**（不要黑底；若有黑底请先抠图）。
- 建议画布与键盘窗口比例接近（当前西西约 224×278）。
- `idle`：日常显示。
- `privacy`：检测到密码输入框时整图切换。
- `blink` / `typing` / `typing_fast`：表情叠化层。

> 旧版 `kid` / `dafeiyu` 皮肤与用户素材覆盖目录已下架；若配置里仍保存了这些品种，启动时会自动落到「西西」。
